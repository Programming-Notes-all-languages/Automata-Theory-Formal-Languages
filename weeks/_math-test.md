# Math Rendering Test (scratch)

Variant A — plain braces:

$$\mathcal{P}(S) = \{\varnothing,\ \{a\},\ \{b\}\}$$

Variant B — bigl/bigr:

$$\mathcal{P}(S) = \bigl\{\varnothing,\ \{a\},\ \{b\}\bigr\}$$

Variant C — left/right:

$$\mathcal{P}(S) = \left\{\varnothing,\ \{a\},\ \{b\}\right\}$$

Variant E — lbrace/rbrace plain:

$$\mathcal{P}(S) = \lbrace\varnothing,\ \lbrace a \rbrace,\ \lbrace b \rbrace\rbrace$$

Variant F — left/right with lbrace/rbrace:

$$\mathcal{P}(S) = \left\lbrace\varnothing,\ \lbrace a \rbrace,\ \lbrace b \rbrace\right\rbrace$$

Inline check — inline math with escaped braces:

The set $S = \{a, b, c\}$ has $\mathcal{P}(S)$ of size $2^3$.
