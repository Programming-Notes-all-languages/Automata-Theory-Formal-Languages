## 1. Languages

### 1.1 Alphabets and Strings

> **Definition (Alphabet).** An *alphabet* $\Sigma$ is a finite, nonempty set of symbols. Lowercase letters such as $a$, $b$, and $c$ usually name individual symbols.

> **Definition (String).** A *string* on $\Sigma$ is a finite sequence of symbols from $\Sigma$. Letters such as $u$, $v$, and $w$ usually name strings.

> **Definition (Concatenation).** The concatenation of strings $w = a_1a_2\cdots a_n$ and $v = b_1b_2\cdots b_m$ appends $v$ to $w$:

$$
wv = a_1a_2\cdots a_n b_1b_2\cdots b_m.
$$

> **Definition (Reverse).** The reverse of $w = a_1a_2\cdots a_n$ is $w^R = a_n\cdots a_2a_1$.

> **Definition (Length).** The length of a string $w$, written $|w|$, is its number of symbols. Concatenation satisfies $|wv| = |w| + |v|$.

> **Definition (Empty String).** The empty string, written $\lambda$, has no symbols. It satisfies $|\lambda| = 0$ and $\lambda w = w\lambda = w$ for every string $w$.

A **substring** is a consecutive sequence of symbols within a string. If $w = vu$, then $v$ is a **prefix** of $w$ and $u$ is a **suffix** of $w$.

For a string $w$ and integer $n \ge 0$, $w^n$ is $w$ concatenated with itself $n$ times. In particular, $w^0 = \lambda$.

### 1.2 String Sets

> **Definition (Kleene Star and Positive Closure).** For alphabet $\Sigma$, $\Sigma^*$ is the set of all strings formed from zero or more symbols of $\Sigma$. The **positive closure** $\Sigma^+$ contains the nonempty strings:

$$
\Sigma^+ = \Sigma^* - \lbrace \lambda \rbrace.
$$

> **Definition (Language).** A *language* on alphabet $\Sigma$ is any subset of $\Sigma^*$. A language may be finite or infinite.

Because languages are sets, union, intersection, and difference apply directly. The remaining common operations are:

| Operation | Definition |
|---|---|
| Complement | $\overline{L} = \Sigma^* - L$ |
| Reverse | $L^R = \lbrace w^R : w \in L \rbrace$ |
| Concatenation | $L_1L_2 = \lbrace xy : x \in L_1,\ y \in L_2 \rbrace$ |

For $n \ge 0$, $L^n$ is $L$ concatenated with itself $n$ times, with $L^0 = \lbrace \lambda \rbrace$ and $L^1 = L$. The **star-closure** and **positive closure** of a language are

$$
L^* = L^0 \cup L^1 \cup L^2 \cup \cdots,
$$

$$
L^+ = L^1 \cup L^2 \cup \cdots.
$$

## 2. Grammars

> **Definition (Grammar).** A grammar is a quadruple

$$
G = (V, T, S, P),
$$

> where $V$ is a finite set of variables, $T$ is a finite set of terminal symbols, $S \in V$ is the start variable, and $P$ is a finite set of productions. The nonempty sets $V$ and $T$ are disjoint.

A production has the form $x \to y$, where $x \in (V \cup T)^+$ and $y \in (V \cup T)^*$. If a sentential form can be written $w = uxv$, applying $x \to y$ produces $z = uyv$, written $w \Rightarrow z$.

> **Definition (Derivation).** $w \Rightarrow^* z$ means that $z$ is derived from $w$ in zero or more production applications. The intermediate strings may contain both variables and terminals.

> **Definition (Sentential Form).** Every string occurring in a derivation, including the start variable and the final terminal string, is a *sentential form*.

> **Definition (Language Generated by a Grammar).** The language generated by $G$ is

$$
L(G) = \lbrace w \in T^* : S \Rightarrow^* w \rbrace.
$$

Only terminal strings belong to $L(G)$; a derivation begins at $S$ and applies productions until it reaches a terminal string.

> **Definition (Equivalent Grammars).** Grammars $G_1$ and $G_2$ are equivalent exactly when they generate the same language:

$$
L(G_1) = L(G_2).
$$

## Quick Reference

| Term / Symbol | Meaning |
|---|---|
| $\Sigma$ | finite, nonempty alphabet |
| $\Sigma^*$, $\Sigma^+$ | all strings / all nonempty strings on $\Sigma$ |
| $\lambda$ | empty string; $|\lambda| = 0$ |
| $wv$, $w^R$, $w^n$ | concatenation, reverse, $n$ repetitions of $w$ |
| $|w|$ | length of $w$ |
| $L \subseteq \Sigma^*$ | language on $\Sigma$ |
| $\overline{L}$, $L^R$ | complement and reverse of a language |
| $L_1L_2$, $L^*$, $L^+$ | language concatenation, star-closure, positive closure |
| $G = (V, T, S, P)$ | grammar: variables, terminals, start variable, productions |
| $w \Rightarrow z$, $w \Rightarrow^* z$ | one-step / zero-or-more-step derivation |
| $L(G)$ | terminal strings derivable from $S$ |
